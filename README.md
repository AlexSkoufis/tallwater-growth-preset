# Tallwater Growth Partners — Growth Capital Firm Preset

A complete, multi-page website for a **fictional** private credit and growth equity firm that backs established, owner-led companies across the Great Lakes. Deep lake teal, ink and a single sky-blue accent; Source Serif 4 + Figtree. A first-load intro assembles the "T over water" mark from four pieces, and every route opens behind a curtain transition.

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · React Router 7 · GSAP 3 (ScrollTrigger, Flip, SplitText) · Lenis · Lucide.

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # typecheck + production build into ./dist
npm run preview        # serve ./dist
npm run images         # rebuild hero WebP files from assets-src/photo
npm run placeholders   # regenerate monogram portraits, logo plates, icons and OG image
```

## Re-skin

- **Firm details**: `src/data/site.ts` (name, email, phone, address, map link, overview PDF, navigation).
- **Content**: `src/data/portfolio.ts`, `team.ts`, `news.ts` and `criteria.ts`. Page-specific copy sits in `src/pages/` and `src/components/home/`.
- **Logo**: `src/components/ui/Logo.tsx`. The mark is four SVG paths tagged `data-petal="tl|tr|bl|br"`; keep those tags (on any four shapes) and the intro still works. The wordmark is live text in the site serif.
- **Icons and OG image**: `public/media/brand/`, generated by `npm run placeholders` from the same mark.
- **Photos**: drop JPEGs into `assets-src/photo/`, run `npm run images`, and reference them as `/media/hero/<file name>`.
- **Portraits and logos**: the team, board and portfolio images are generated placeholders. Replace `public/media/team/<slug>-480.webp` / `-960.webp` (2:3), `public/media/board/*.webp` and `public/media/portfolio/<key>-480.webp` (square, on white) with real files of the same names.
- **Colour & type**: tokens at the top of `src/index.css`.

## Motion and accessibility

- All animation runs in `useGSAP` / `gsap.context` scopes and is skipped for `prefers-reduced-motion`.
- Lenis smooth scroll is synced with ScrollTrigger; route changes play a curtain transition and restore focus.
- Skip link, labelled navigation, keyboard-operable dropdowns, filters and dialog.

## Deploy

Static SPA output in `dist/`. SPA fallbacks are included for Vercel (`vercel.json`) and Netlify (`public/_redirects`). The demo ships with `noindex` (in `index.html`, `vercel.json`, `public/_headers` and `public/robots.txt`); remove it when the site goes live.

## Demo content

Tallwater Growth Partners, its funds, people, portfolio companies, figures, quotes and articles are fictional. The email addresses use the reserved `.example` domain and the phone number is a 555 placeholder. The fund overview PDF is a placeholder.
